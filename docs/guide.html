Read the display accurately

What the viewer shows

RoboMNIST combines robot state with recordings from three sensor modules. A useful interpretation starts by keeping measurement and illustration distinct.

Measured in the trial

Motion and sensing

Robot data: the timestamped joint angles and end-effector coordinates come from the released position file. The highlighted path is a recorded end-effector trajectory.

Sensor data: the camera frames, WiFi channel state, and microphone signal come from the corresponding recording. The viewers align their displays by elapsed time.

The paper describes synchronized collection. The interactive display does not claim camera-to-robot calibration or subframe timing precision.

Reconstructed for explanation

Robot model and room

Moving arm: simplified 3D robot geometry follows the recorded joint angles through a forward-kinematics model. The rendered link shapes and joint centers are a reconstruction.

Room: the lab context follows the paper's stated footprint, but object and robot placements are schematic. It cannot establish distances from camera pixels.

The colored “writing” interval is an estimated near-plane segment, not a provided stroke annotation or contact measurement.

The readable digit

Why a 2 can look like a 5

The source end-effector coordinates are in a robot frame. Looking at the stroke from opposite sides reverses the horizontal direction and can make a digit appear mirrored.

The front-view projection displays horizontal position as −EE y so the digit can be read from the chosen side. This changes only the plot's display direction; it does not modify the recorded values.

“Readable front view” is a plotting convention, not a claim that it exactly matches any camera's optical viewpoint.

An idea to test

What can each modality add?

The robot file supplies a direct geometric path. Video shows the physical scene. WiFi CSI and audio describe changes in the environment through different sensing mechanisms.

Try pausing at the same time across views, then compare a moving interval with a quieter interval. Similar timing can suggest a relationship; this descriptive demo does not itself demonstrate recognition accuracy or causation.

Give the dataset credit

Use RoboMNIST in your work

The authors ask users of the dataset, code, or repository descriptions to cite the Scientific Data paper. Include the dataset DOI when sharing a derived plot, lesson, or demo so readers can reach the original recordings.
